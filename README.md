# Louis Music Player for Windows 11

往年のポータブルオーディオプレイヤー風のデスクトップ音楽プレイヤーです。
暗い液晶画面がウインドウいっぱいに広がるデザインです。

- 液晶画面・操作アイコンまで、すべてコードによるベクター描画
- **フォルダごとのループ再生** / **1曲だけのループ再生** / シャッフル
- ループ・シャッフルの状態が一目で分かる表示（下記参照）
- プレイリストの作成・再生・削除（自動保存）
- 追加した音楽フォルダを画面から削除可能（フォルダ本体は残ります）
- ハイレゾ再生対応（`HR` バッジ表示）
- 再生キューと再生位置を記憶し、次回起動時に続きから再生（選曲中の曲も復元）
- フォルダ／プレイリスト画面のスクロール位置も記憶し、次回起動時に同じ位置で開く
- フォルダ内の曲は**トラック番号の小さい順**に並びます
- **10バンド イコライザー / Bass Boost / プリセット / 曲ごとの音量自動調整**（下記参照）
- **Live Effect（会場の響き＋観客の拍手・歓声）**（下記参照）

> 第三者（家電メーカー等）のブランド名・ロゴ・ワードマークは一切使用していません。
> 配布してもブランド権を侵害しないよう、画面上のロゴ文字は排除しています。

## 1. 配布用ファイル（かんたん）

**`dist\Louis Music Player.exe`** がそれ一枚で動く実行ファイルです。

- Python のインストールは不要です。受け取った人が `Louis Music Player.exe` を
  ダブルクリックするだけで起動します。
- Windows 10 / 11 (64bit) 対応。
- 初回起動は展開のため数秒かかることがあります。

配布するときは `Louis Music Player.exe` をそのまま渡してください。

## 2. 自分でビルドする場合

### 2-1. 実行ファイル (.exe) を作る

```
install.bat    → 初回のみ（.venv 作成 + 依存関係の導入）
build_exe.bat  → dist\Louis Music Player.exe を生成
```

`build_exe.bat` は PyInstaller を使い、`assets`（アイコン等）を同梱した
単一ファイルの `Louis Music Player.exe` を `dist\` に出力します。

### 2-2. ソースから直接実行（開発用）

```
run.bat        → 起動（コンソール非表示）
run_debug.bat  → ログ表示付き起動
run.ps1        → PowerShell から起動
```

手動の場合:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m player
```

## 3. 使い方

### 画面下の 4 つのアイコン

| アイコン | 機能 |
|----------|------|
| ←（戻る） | 前の画面 / Now Playing に戻る |
| フォルダ | フォルダブラウザ（音楽フォルダの追加・階層移動） |
| ≡ リスト | プレイリスト一覧 |
| 工具箱 | 設定 |

### Now Playing 画面

- 中央の円形ボタン: ⏮ 前の曲 / ⏯ 再生・一時停止 / ⏭ 次の曲
- 左の小さなアイコン: **シャッフル**、右の小さなアイコン: **リピート（ループ）**
- 進行バー: ドラッグでシーク、クリックでジャンプ
- `HR` バッジ: ハイレゾ音源を再生中に表示

### ループ / シャッフルの状態表示（改善点）

「今どちらのモードなのか分からない」問題を解消するため、3 か所で状態を示します。

1. **画面中央のポップアップ** — ボタンを押した瞬間に
   「リピート再生: オフ / 全曲（フォルダ） / 1曲」「シャッフル再生: オン / オフ」を表示。
2. **ボタン自体のハイライト** — 有効なときは白く強調（リング＋塗り）。
   1曲ループは「1」付きアイコン、全曲ループは通常のリピートアイコン。
3. **画面右上の常時マーカー** — ループ状態とシャッフル状態をアイコンで常に表示。

ループモードは押すたびに「オフ → 全曲（フォルダ） → 1曲 → オフ…」と切り替わります。

### 音楽フォルダの追加と削除（改善点）

- 追加: フォルダ画面の「＋ フォルダを追加」から選択。
- 削除: フォルダ画面で対象フォルダを**右クリック → 「このフォルダを一覧から削除」**。
  - プレイヤーの一覧から見えなくなるだけで、**パソコン上のフォルダや音楽
    ファイルは削除されません**（エクスプローラーにはそのまま残ります）。
  - 削除時は確認ダイアログが表示されます。

### プレイリスト

- リスト画面の「＋ 新規プレイリスト」で作成（現在のキューを登録）。
- 曲の行を**右クリック → 「プレイリストに追加」**で 1 曲ずつ追加。
- 保存先: `%APPDATA%\Louis Music Player\playlists.json`（自動保存）。

### イコライザー / 音質調整

設定画面の **「音質調整（イコライザー）」** から開きます。

- **10 バンド EQ**（31Hz / 63Hz / 125Hz / 250Hz / 500Hz / 1kHz / 2kHz / 4kHz /
  8kHz / 16kHz、各 ±12dB）
- **Bass Boost**（+15dB まで、低域シェルフ）
- **プリセット**: フラット / ロック / ポップ / ジャズ / クラシック / ダンス /
  ライブ / ボーカル / 低音 / 高音
- **カスタム設定の保存**: 「カスタム設定を保存」で好きなカーブに名前を付けて保存
  （プリセット一覧に追加されます）
- **音量を自動調整（ダイナミックノーマライザー）**: 曲ごとに音量を解析して、
  曲が変わっても音量が揃うように自動調整します（初回のみ解析のため少し待ちます）
- 設定は自動保存され、次回起動時にも適用されます
  （`%APPDATA%\Louis Music Player\settings.json` / 解析結果は `loudness.json`）

### ライブ演出（Live Effect）

設定画面の **「ライブ演出（Live Effect）」** から開きます。ON にすると、再生中の曲に
会場の残響と観客の拍手・歓声を重ねます。元の音はそのまま残ります。

- **会場**: アリーナ / ライブハウス / コンサートホール / ドーム / 野外フェス / スタジアム
  （プリディレイ・残響時間・観客ノイズが会場ごとに変わります）
- **調整**: 演出の強さ / 歓声の音量 / 立体感（広がり）
- **自動演出**: 曲を解析し、開始（拍手）／サビ前（盛り上げ）／サビ入り（歓声）／
  曲末（大歓声）を自動で配置します
- **手動で追加**: Now Playing の **「LIVE」** ボタンで ON/OFF、**「歓声を追加」** で
  現在位置に歓声を追加。ライブ演出画面の **「＋ 現在位置に追加」** でも追加でき、
  一覧のダブルクリックでその位置へシーク、選択した歓声の削除・全消去も可能です
- 設定と曲ごとの手動配置は自動保存されます
  （`%APPDATA%\Louis Music Player\settings.json`）
- 拍手・歓声は OtoLogic の音源（CC BY 4.0）を使用しています。会場の残響と
  サビ前の盛り上げ音はアプリ内で合成しています

### キーボード / マウス操作

| 操作 | 機能 |
|------|------|
| `Space` | 再生 / 一時停止 |
| `←` / `→` | 5 秒シーク |
| `Ctrl+←` / `Ctrl+→` | 前の曲 / 次の曲 |
| `↑` / `↓` | 音量 |
| `L` | ループモード切替 |
| `S` | シャッフル切替 |
| `F` / `P` | フォルダ / プレイリスト画面 |
| `Esc` | 戻る |
| マウスホイール | 音量（画面上部に音量バーを表示） |
| ドラッグ & ドロップ | 音楽ファイル / フォルダをドロップで再生 |

## 4. 対応フォーマット

PyAV（FFmpeg バインディング）でデコードし、10 バンド EQ を適用したうえで
sounddevice から出力します。追加で VLC や FFmpeg のインストールは不要です。

```
.mp3 .mp2 .m4a .m4b .m4r .m4p .mp4 .aac .alac
.flac .wav .wave .aiff .aif .aifc .w64 .rf64
.ogg .oga .opus .spx .wma .asf .ape .wv
.dsf .dff .mka .mpc .ac3 .tta .caf .amr .3gp
```

特に **MP3 / M4A(AAC) / FLAC / WAV / AIFF / OGG / Opus** はメタデータ
（タグ・アートワーク・サンプルレート・ビット深度）も読み取り、画面に表示します。

### ハイレゾ再生

- 24bit / 96kHz や 24bit / 192kHz などの PCM 系（FLAC / WAV / AIFF / ALAC）を
  デコードして再生します。ハイレゾ判定時は `HR` バッジを表示。
- 判定の目安: ビット深度 > 16bit、または サンプルレート > 48kHz、または DSD。
- 再生は既定の出力デバイスのサンプルレート（通常 48kHz / ステレオ）に
  リサンプリングして EQ を通したうえで出力します。

## 5. フォント（SST JP 相当）

SST / SST JP は独自フォントで一般配布されていないため、SST に近い
ヒューマニスト系サンセリフを自動選択します。

1. `SST JP` / `SST`（導入済みの場合のみ）
2. `Yu Gothic UI`（Windows 11 標準）
3. `Noto Sans JP`（`NotoSansJP-VF.ttf` を自動登録）
4. `Meiryo UI` → `Segoe UI`

`player/theme.py` の `FONT_CANDIDATES` を編集すれば優先フォントを変更できます。

## 7. トラブルシューティング

- **exe が起動しない / ウイルス対策で止まる** → PyInstaller 製の単一 exe は
  誤検知されることがあります。SmartScreen の「詳細情報 → 実行」を選ぶか、
  配布元を信頼済みに設定してください。
- **ソースから起動しない** → `run_debug.bat` でログを確認。依存関係が未導入なら
  `install.bat`。
- **`python` が見つからない** → `py -3` を確認。Microsoft Store 版の
  `python.exe`（WindowsApps のエイリアス）は環境により失敗するため、
  `python.org` 版の使用を推奨します。
- **一部の曲が再生できない** → その拡張子が FFmpeg でデコード可能か確認（§4）。
  破損ファイルはスキップされます。
- **ジャケットが出ない** → 埋め込みアートワークが無い場合は既定の音符ロゴを表示。
